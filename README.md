This is a [Next.js](https://nextjs.org) website that will be used for my upcoming LMS on [rajscape.com](https://rajscape.com)

## Getting Started

Clone, install and verify dependencies.

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Acquire or generate new environment variables

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses Prisma as ORM, T3 as `.env` validation, Neon as backend, and better-auth as authentication.
